# NAVTORG — стартовый проект

Первая автономная версия рабочего места риелтора. Открывается как статический сайт, без сборки и без обязательного сервера.

## Запуск
Открой `index.html` в браузере. Данные сохраняются в `localStorage` этого браузера.

## Что уже работает
- Рабочий стол и счётчики объектов.
- Добавление объектов с проверкой правил.
- Собственная локальная база и поиск/фильтр по статусу.
- Отказ для зданий общей этажностью 1–3 этажа включительно.
- Отказ для рассрочки и кредитной схемы с остатком платежа.
- Третий этаж квартиры разрешён, если здание выше трёх этажей.
- Неизвестная этажность или неподтверждённая схема оплаты отправляют объект в черновики.
- Фильтры лифта, ремонта, мебели, цены без мебели и видео.
- Справочник территорий с возможностью локально добавлять города/районы.
- Ташкент-город отделён от Ташкентской области; метро помечено только для города Ташкент.
- Экспорт локальной резервной копии JSON.

## Важно: ограничения v0.1
- Это не многопользовательская общая база: localStorage не синхронизирует устройства и сотрудников.
- Географический seed включает все 14 верхнеуровневых территорий и основные стартовые локации для Навои/Ташкентской области/города Ташкент. Полный актуальный список 177 районов и городов, а также махаллей нужно загрузить из официального классификатора SIAT/Stat.uz и проверить перед использованием.
- Карта, спутниковые снимки, маршруты и линии метро пока являются подготовленным местом интеграции, не подключёнными сервисами.
- Нет Firebase, авторизации и серверной проверки. Не загружайте сюда реальные персональные данные клиентов до подключения защищённого backend.
